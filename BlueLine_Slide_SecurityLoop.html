4 Agent Pipeline
👁️
WATCHTOWER
Finding Discovery
Monitors Fortify SSC continuously. Detects new findings and publishes them to the pipeline automatically.
↓
🛡️
BULWARK
Triage & Classify
Classifies each finding — CRITICAL, HIGH, NEEDS REVIEW, or FALSE POSITIVE — with OWASP mapping and attack scenario.
↓
🔧
FORGE
Fix PR Generation
Writes the corrected code and creates a draft Pull Request in Azure DevOps — ready for a developer to review.
↓
📝
STEWARD
Audit Log
Writes every decision to an immutable audit log — classification, action taken, human gate status. 7-year retention.
